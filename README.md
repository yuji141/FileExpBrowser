# ファイル検索・タグ管理システム

## 概要

ドキュメントフォルダ内のファイルを検索・分類・管理する業務ツール

- Excelをデータベースとして使用
- ブラウザで検索・タグ付け
- PowerShellでファイル操作
---

## Demo

https://yuji141.github.io/FileExpBrowser/---

---

## システム構成

| 構成       | 役割               |
| ---------- | ------------------ |
| Excel      | データベース       |
| VBA        | 差分更新・JSON出力 |
| ブラウザ   | 検索・タグ付け     |
| PowerShell | 削除・リネーム     |

---

## 基本フロー

### ① 検索・タグ付け

1. ブラウザを開く
2. ファイル検索
3. タグ付け

---

### ② ファイル操作

1. ファイルを選択
2. ボタンを押す（削除 / リネーム）
3. 表示されたメッセージに従いPowerShellで実行

---

### ③ DB更新（重要）

1. Excelを開く
2. 「DB更新」ボタンを押す
3. ブラウザに戻る（自動更新される）

---

## 注意事項

### DB更新について

以下の操作後は必ず実行すること

- ファイル削除
- ファイルリネーム

理由：
ブラウザはExcelのデータを表示しているため、
OS上の変更は自動反映されません

---

### 表示のズレについて

以下は仕様です

- 削除後 → 一時的にファイルが残る
- リネーム後 → 古い名前のまま表示される

→ DB更新で解消される

---

### タグ付けについて

- ブラウザ内（localStorage）に保存される
- 画面更新では消えない

---

## 操作ボタン

| ボタン           | 内容                   |
| ---------------- | ---------------------- |
| パスコピー       | explorerコマンドコピー |
| 削除コマンド     | 削除コマンドコピー     |
| リネームコマンド | リネームコマンドコピー |
| タグ付け画面     | 編集画面へ             |

---

## 操作ログ

画面下に履歴が表示される

例：

削除コマンドコピー：xxx  
リネームコマンドコピー：xxx → xxx

---

## 警告表示

削除・リネーム後に表示

※ Excelを更新してください（変更は未反映）

---

## 自動更新

- Excel操作後、ブラウザに戻ると自動更新
- 手動リロード不要

---

## 技術構成

- JavaScript（UI・検索）
- localStorage（タグ保存）
- VBA（データ同期）
- JSON（データ受け渡し）

---

## 設計方針

- データと操作の分離
- 削除・リネームは直接実行しない
- Excelを中心に構成
- ブラウザは操作UI

---

## 補足

削除・リネームはブラウザでは実行されない

必ずPowerShellで実行すること
